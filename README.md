# Phone Store Project

Проект реализует работу с товарами и категориями для магазина.

## Функционал
- Создание объектов Product и Category
- Подсчёт количества категорий и продуктов
- Подгрузка данных из JSON
- Вывод информации о товарах и категориях в консоль
# Установка зависимостей
Клонируем репозиторий
```
git clone <https://github.com/mollygreu/store_phone>

```
# Создаем и активируем виртуальное окружение через poetry
```
poetry install
poetry shell
```
# Запуск демонстрации
```
python main.py
```
